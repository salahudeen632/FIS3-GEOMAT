# FIS3-GEOMAT

## Enhancing Geothermal Energy Systems with Innovative Materials

This repository contains numerical developments and case studies performed as part of the FIS3 Starting Grant project.

**Project:** Enhancing Geothermal Energy Systems with Innovative Materials  
**Project code:** FIS-2024-02697  
**CUP:** B53C25003860001  
**Principal Investigator:** Salahudeen Mohamed Kunju

## Metal Foam–PCM Modeling for BHEs

This work includes numerical modeling of metal foam–enhanced phase change materials (PCMs) for borehole heat exchangers (BHEs).

## Repository Structure

- `benchmark/` – Benchmark and validation studies
- `solver/` – OpenFOAM solver development
- `meshSensitivityStudy/` – Mesh sensitivity studies
- `timeSensitivityStudy/` – Time-step sensitivity studies
- `mainCaseStudies/` – Main simulation case studies
